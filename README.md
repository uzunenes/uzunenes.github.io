# uzunenes.github.io

Personal site, served at [uzunenes.com](https://uzunenes.com) by GitHub Pages (Jekyll, minima theme).

- Edit `index.md` or `about.md` directly on GitHub; the site rebuilds in a minute or two.
- Posts go in `_posts/YYYY-MM-DD-title.md`; unfinished ones in `_drafts/`.
- `cv.md` and `assets/enes-uzun-cv.pdf` are generated from the private CV repo; don't edit them here.
